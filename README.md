## 2. 프로젝트 개요 및 PRD 핵심 명세 (v1.0 초안)

* **목표 사용자:** 투자 경험이 적은 초보 투자자, 객관적인 거래 습관 점검 및 감정적·계획 외 매매를 줄이고 싶은 사용자
* **핵심 원칙:**
  * 실제 체결 기록(주문 ID, 체결 시각·수량)을 기준으로 정해진 수식으로 판정하며, 미체결 주문은 거래로 계산하지 않음
  * AI는 계산된 점수와 실제 거래 기록을 근거로 행동 패턴 설명 및 개선 제안만 제공 (종목 매수·매도 추천 및 근거 없는 감정 단정 배제)
  * 프로젝트 시작 시 설정한 평가 기간(최소 2주)은 진행 중 변경 불가

### 핵심 기능 요구사항
| 기능 영역 | 주요 요구사항 |
| --- | --- |
| **모의투자** | 실제 과거 주가 데이터를 반영한 가상 자금 모의 매수·매도 지원 |
| **프로젝트 설정** | 평가 기간 설정(최소 2주) 및 기간 내 거래 기록 수집 |
| **거래 기록** | 체결 내역, 주문 ID, 체결 시각 및 수량 누적 기록 |
| **행동 점수 (4대 영역)** | **위험 관리(RM)**, **계획 준수(PA)**, **행동 일관성(BC)**, **시장 상황(MC)** 영역별 평가 |
| **AI 피드백** | 산출 점수와 실제 거래 기록을 근거로 반복 행동 패턴 및 개선 방향 안내 |
| **종료 결과** | 최종 종합 점수, 주요 행동 패턴, 개선 제안 및 종료 사유(예: 체결량 미달) 표시 |

### 행동 점수 산정 및 주요 평가 기준
* **점수 계산:** 4개 영역 모두 **100점**에서 시작하여 규칙 위반 시 정해진 점수를 감점 (영역별 최저 0점, 동일 규칙 중복 감점 불가)
* **종합 점수:** 4개 영역(`RM`, `PA`, `BC`, `MC`) 점수의 **산술평균**
* **BC-01 (거래 빈도 평가):** 첫 1주간 거래 기록을 수집해 기준 일평균을 산출한 뒤 재평가하며, 일일 거래 횟수가 기준 평균의 **3배 이상**일 경우 20점 감점 (첫 주 평균 0건 시 `체결량 미달`로 프로젝트 조기 종료)
